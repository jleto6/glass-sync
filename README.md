### GlassSync 
GlassSync enables real-time computer vision overlays on the Meta Ray-Ban display HUD by routing live Messenger video through a local processing system and back into the glasses via a virtual camera.

Along with downloading media, GlassSync can:

- Attaches to an active Messenger session
- Captures incoming video frames live
- Streams frames to a local processing system
- Renders processed overlays
- Publish the augmented feed to a virtual camera so it appears directly on the Meta Ray-Ban display

### How it Works:
When you initiate a video call from your Meta Glasses to a dedicated Messenger account:
	1.	GlassSync attaches to the Messenger tab.
	2.	It captures live frames from the call.
	3.	Frames are sent to a local processing module.
	4.	The processed output is streamed back through a virtual camera.
	5.	The glasses display the augmented video feed.
